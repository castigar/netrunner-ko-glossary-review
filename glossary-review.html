용어 직접 등록

extract-terms가 세그먼트 방식으로 놓치는 구문 용어(advancement token 등)를 수동 등록합니다. id는 term. 접두어로 자동 생성됩니다(직접 지정 가능). 등록 즉시 approved 상태입니다.

항목 데이터는 이 HTML 생성 시점의 glossary/ 스냅샷입니다. extract-terms 재실행 후에는 스크립트로 이 파일을 재생성하세요. 선택 상태는 브라우저(localStorage)에 저장되며 사전 내용이 바뀌면 자동 초기화됩니다.
